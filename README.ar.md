## عرض النماذج

تستخدم النماذج التالية مراجع أصلية مختلفة. أنشأ Panel 118 كل عمل بصورة مستقلة وفي جولة توليد واحدة، وقد أزيلت البيانات الوصفية للذكاء الاصطناعي. النماذج الأفقية تقسيمها صارم 50:50: الواقع يساراً والتصميم يميناً؛ والنماذج العمودية تقسيمها صارم 50:50: الواقع أعلى والتصميم أسفل. نصوص النماذج مولّدة بالإنجليزية ومستندة إلى كل صورة أصلية.

## الحالات المناسبة والمشكلات التي يحلها

عندما يكون الموضوع صغيراً أو الخلفية مزدحمة أو تحتاج صورة عادية إلى تعبير منشور مستقل، يحفظ **Panel 118** الصورة الحقيقية ويعيد إخراج منطقة التصميم كتجميع موضوعي بقلم الغرافيت. يقرر ما يستحق البقاء ثم يعيد بناء المقاييس والمواضع والفراغ.

### مناسب عندما

- تريد هوية الصورة وملمسها مع ملصق تحريري ذي حكم فني مستقل.
- تريد علاقات موضوعية واضحة دون تتبع كل عنصر أو نسخ التكوين الأصلي.
- تفضل الغرافيت الأبيض والأسود والتهشير الطبيعي والفراغ الواسع على الواقعية الأكاديمية المعقدة.
- تحتاج إلى أعلى/أسفل أو يسار/يمين أو تصميم فقط أو خلفيات أو معالجة مجلد.

### ما الذي يعالجه

- يحسن الموضوع الصغير والخلفية المزدحمة والتكوين العادي بفاعلية.
- يبني التجميع الموضوعي بالحذف وإعادة الترتيب والقص وتغيير المقاييس.
- يجعل الفراغ عنصراً فاعلاً بالأشكال الموجبة والسالبة والكثافة والتوازن غير المتماثل.
- يولد كل أصل باستقلال في جولة واحدة، ويثبت المقارنة في منطقتين فقط بنسبة 50:50.

يُحفظ الأصل الصيني حرفياً بوصفه المرجع الإبداعي والجمالي الوحيد وقت التشغيل. اللغات الأربع الأخرى ترجمات قراءة كاملة لا تعيد كتابة تعليمات التوليد.

**البصمة:** قلم غرافيت · تهشير طبيعي · قليل من التهشير المتقاطع · رمادي خفيف · تجميع موضوعي · حذف فعّال · فراغ واسع · 1–2 لون اختياري من ألوان التعرّف في الأصل

## فحص الملاءمة السريع

| ما تريد معرفته | ما يقدمه Panel 118 |
|---|---|
| تكوين الأصل عادي؟ | يعيد إخراج التصميم باستقلال عن التخطيط الأصلي. |
| هل تبقى الصلة واضحة؟ | يحتفظ بالفكرة ومسار البنية والعلاقات الأكثر معنى. |
| رسم واقعي تقليدي؟ | أشكال رخوة وعفوية قليلاً بإحساس اسكتش توضيحي سريع. |
| أحجام متعددة؟ | أربعة أنماط ونسب شائعة ومخصصة وبكسلات دقيقة ومعالجة مجلدات. |

## منطق التحويل

فهم الفكرة وعلاقات البنية → الحذف الفعّال → إعادة الترتيب والقص → محيط غرافيت وتهشير طبيعي ورمادي خفيف → تكوين تحريري بالفراغ وقليل من النص.

## سمات النتيجة

- يغلب الأبيض والأسود أو رمادي الغرافيت الطبيعي، مع تأكيدات ضئيلة اختيارية من 1–2 لون أصلي.
- محيطات رخوة وعفوية، وتهشير طبيعي وقليل من التهشير المتقاطع.
- يمكن إزاحة الموضوع عن المركز أو للحافة أو تعليقه أو تكبيره أو تصغيره أو قصه جزئياً.
- الفراغ يساوي الموضوع أهمية؛ الحذف أفضل من ملء اللوحة.
- كلمات أو عبارات قليلة من الفكرة أو المكان أو الشعور أو الاستعارة بلا لغة أو خط أو صيغة ثابتة.
- يتجنب نسخ الصورة والخلفيات المعقدة والتفاصيل الزائدة والتخطيط الميكانيكي والقوالب.

## أنماط الإخراج الأربعة

- `top-bottom`: منطقتان أفقيتان كاملتا العرض فقط؛ الواقع في الأعلى والتصميم في الأسفل، 50% لكل منهما.
- `left-right`: منطقتان عموديتان كاملتا الارتفاع فقط؛ الواقع يساراً والتصميم يميناً، 50% لكل منهما، ولا يتحول إلى تخطيط علوي/سفلي.
- `design-only`: تعرض اللوحة الكاملة ترجمة Panel 118 التصميمية فقط، وتبقى الصورة مرجعاً غير ظاهر.
- `wallpaper-pack`: ينشئ عملاً كاملاً للهاتف وiPad وسطح المكتب والساعة، إما كعائلة `linked` أو أربعة أعمال `independent`.

يمكن جمع الأنماط والأحجام. تشمل النسب `1:1` و`3:4` و`4:3` و`4:5` و`5:4` و`2:3` و`3:2` و`9:16` و`16:9` و`21:9` و`5:7` و`7:5` والبكسلات الدقيقة. يمكن أن يكون النص مولداً أو حرفياً من المستخدم أو غائباً. عند إدخال مجلد، تُعالج كل صورة بمعزل عن الأخرى مع إعدادات تسليم مشتركة، وتوضع ملفات PNG النهائية مباشرة في مجلد مهمة جديد واحد.

## البدء

```bash
git clone https://github.com/nevertoday/xxd-panel-118.git
npx skills add https://github.com/nevertoday/xxd-panel-118 --skill xxd-panel-118
```

بعد التثبيت أعد تشغيل جلسة Agent ثم استدعِ `$xxd-panel-118`. ويمكن إضافة `--global --agent codex --yes` للتثبيت على مستوى المستخدم.

```text
/xxd-panel-118 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale ar-SA
/xxd-panel-118 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-118 photo.jpg --mode design-only --size 9:16 --text none
/xxd-panel-118 ./photos --mode design-only --size auto,3:4 --text prompt --locale ja-JP
```

راجع [SKILL.md](SKILL.md) لعقد التشغيل الكامل، ومهايئ التشغيل [بالإنجليزية](references/xxd-panel-118-prompt.en.md) أو [بالصينية](references/xxd-panel-118-prompt.zh-CN.md).
